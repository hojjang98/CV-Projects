# 🧠 Computer Vision Project Collection

This repository contains a collection of deep learning projects focused on computer vision tasks such as image classification, pose estimation, and real-time webcam inference.

---

## 📂 Folder Structure

```bash

CV-Projects/
├── food-image-classification
├── pose-sync-evaluator
├── real-time-daily-activity-recognizer
└── recyclable-waste-classification

```

## 📌 Projects

- [Food Image Classification](./food-image-classification)  
  CNNs and transfer learning applied to food image datasets for classification.  

- [Pose Sync Evaluator](./pose-sync-evaluator)  
  Pose estimation with similarity metrics (cosine similarity, DTW) for movement evaluation and feedback.  

- [Real-Time Daily Activity Recognizer](./real-time-daily-activity-recognizer)  
  Real-time activity classification using webcam input and CNN-based models.  

- [Recyclable Waste Classification](./recyclable-waste-classification)  
  Image classification of recyclable materials (cardboard, glass, metal, etc.) using CNN baselines and transfer learning (ResNet, EfficientNet).  



## 🛠️ Tools & Technologies

- `OpenCV`, `Matplotlib`, `scikit-learn`  
- `Jupyter Notebook`, `Streamlit`, `Selenium`
